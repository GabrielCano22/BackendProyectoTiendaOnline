# Backend Tienda Online - La Tienda de Gerardo

Proyecto de tienda online desarrollado en Python aplicando Programación Orientada a Objetos (POO).

## Requisitos
- Python 3.10 o superior
- Black (formateador de código)

## Instalación
pip install black

## Cómo ejecutar
Desde la raíz del proyecto ejecutar:
python main.py

## Estructura del proyecto
BackendProyectoTiendaOnline/
├── main.py
├── tienda.py
├── usuario.py
├── Carrito.py
└── CLASES/
    ├── Producto.py
    ├── Alimentos.py
    ├── Bebes.py
    ├── CuidadoPersonal.py
    ├── Hogar.py
    ├── Licoreria.py
    ├── Mascotas.py
    ├── ProductosElectronicos.py
    └── Ropa.py

## Funcionalidades
- Catálogo de productos por categorías
- Carrito de compras con descuentos por volumen
- Generación de factura
- Panel de administrador para gestionar productos
